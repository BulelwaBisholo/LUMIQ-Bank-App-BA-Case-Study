# Publishing LUMIQ to GitHub

1. Create a new public repository named `LUMIQ-Bank-App-BA-Case-Study`.
2. Use the README in this package as the repository landing page.
3. Upload the contents of this package (not the outer ZIP file).
4. Check that the two process-map previews render in the README.
5. Open the PDF and PowerPoint from GitHub to confirm they display correctly.
6. Keep the fictional-project disclaimer visible.
7. Add the repository link to the portfolio website only after checking the public repository.

Suggested GitHub repository description:
`Fictional digital-banking BA case study demonstrating stakeholder analysis, AS-IS/TO-BE process design, requirements, user stories, traceability and UAT.`

Suggested topics:
`business-analysis`, `business-analyst-portfolio`, `requirements-engineering`, `process-mapping`, `user-stories`, `uat`, `digital-banking`
